# 🍕 Pizza Sales Data Analysis using SQL

## 📌 Project Overview

This project analyzes pizza sales data using SQL to extract meaningful business insights. The goal is to understand customer behavior, sales trends, and revenue patterns for better decision-making.

---

## 🎯 Objectives

* Analyze total orders and revenue
* Identify top-selling pizzas
* Understand sales trends by time and category
* Evaluate contribution of each pizza type to revenue

---

## 🛠️ Tools & Technologies

* SQL (MySQL / PostgreSQL)
* Data Analysis Techniques
* Joins, Aggregations, Window Functions

---

## 📊 Key Analysis Performed

* Total number of orders placed
* Total revenue generated
* Highest priced pizza
* Most common pizza size ordered
* Top 5 most ordered pizza types
* Category-wise sales distribution
* Hourly order trends
* Daily average orders
* Top 3 pizzas by revenue
* Revenue contribution percentage
* Cumulative revenue analysis

---

## 📈 Key Insights

* Peak orders occur during evening hours
* Certain pizza categories dominate revenue
* Few pizza types contribute majority of sales (Pareto effect)
* Medium/Large sizes are most preferred

---

## 💡 Business Recommendations

* Focus marketing on top-selling pizzas
* Optimize inventory based on peak hours
* Introduce combo offers on popular sizes
* Improve low-performing categories

---

## 📂 Dataset

Dataset contains order details, pizza types, sizes, and pricing.
